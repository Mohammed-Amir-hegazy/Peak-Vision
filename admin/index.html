ربط لوحة التحكم بالموقع (GitHub)

الموقع محفوظ على GitHub، ولوحة التحكم بتنشر التعديلات مباشرة عليه. محتاج Token مرة واحدة بس على كل جهاز.

إزاي أعمل Token؟ (دقيقة واحدة)
  1. افتح صفحة إنشاء Token.
  2. اكتب أي اسم، واختار مدة الصلاحية.
  3. في Repository access اختار Only select repositories واختار مستودع الموقع.
  4. في Permissions ← Repository permissions خلي Contents = Read and write.
  5. اضغط Generate token وانسخه والصقه هنا.
