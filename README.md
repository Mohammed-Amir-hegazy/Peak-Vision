# PEAK VISION — الموقع + لوحة التحكم

الموقع بنفس الشكل والتفاصيل بالظبط، وكل محتواه بتتحكم فيه من **لوحة تحكم** عادية بالإيميل وكلمة المرور. المحتوى والصور متخزنين في قاعدة بيانات (Supabase)، وأي تعديل بيظهر على الموقع فورًا، من غير GitHub ولا أي Token.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | الموقع (نفس التصميم الأصلي بالظبط) |
| `assets/site.js` | بيبني الصفحة من المحتوى اللي في قاعدة البيانات |
| `assets/config.js` | بيانات الاتصال بقاعدة البيانات (Supabase) |
| `admin/` | لوحة التحكم — افتحها من `your-site.com/admin` |
| `supabase/setup.sql` | إعداد قاعدة البيانات (بيتعمل مرة واحدة) |
| `content.json` | نسخة احتياطية من المحتوى، بيستخدمها الموقع لو قاعدة البيانات مش متاحة |
| `peak_vision_portfolio.html` | النسخة القديمة زي ما هي (مش مستخدمة) |

## لوحة التحكم بتتحكم في إيه؟

- **كل النصوص**: الهيدر، الواجهة، من نحن، الأرقام، العملاء، الخدمات، الأعمال، التواصل، الفوتر.
- **المشاريع / الأعمال**: إضافة، حذف، تعديل، نسخ، إخفاء مؤقت، وتغيير الترتيب (سحب وإفلات أو أسهم). الترقيم 01، 02… بيتظبط لوحده. وفيه زر يجيب صورة الفيديو من يوتيوب تلقائي.
- **العملاء**: إضافة شعارات (أو رفع كذا شعار مرة واحدة)، ترتيب، حذف، وربط كل شعار بلينك.
- **التواصل واللينكات**: أزرار الواتساب والاتصال، روابط القائمة، أعمدة الفوتر، والسوشيال ميديا.
- **ترتيب الأقسام**: اسحب الأقسام في القائمة الجانبية (أو استخدم زرار ↑ ↓)، وتقدر تخفي أي قسم.
- **زر «عرض المزيد»**: في كل قسم فيه عناصر كتير (العملاء، الخدمات، الأعمال، الأرقام) فيه خانة «عدد العناصر الظاهرة». لو العناصر زادت عن الرقم ده هيظهر زر «عرض المزيد» (و«عرض أقل»). اكتب `0` لإظهار الكل بدون زر. القيم دلوقتي: العملاء 12، الأعمال 6، الخدمات 6.
- **الألوان** وعنوان الموقع ووصفه لمحركات البحث والأيقونة.
- **معاينة مباشرة** (كمبيوتر / تابلت / موبايل) قبل النشر، و**تراجع** عن أي خطوة، وحفظ تلقائي للتعديلات على جهازك لحد ما تنشر.
- **النسخ السابقة**: كل نشر بيحفظ النسخة اللي قبله تلقائي (آخر 50)، وتقدر ترجّع أي واحدة من «المزيد ← النسخ السابقة».
- **الحساب**: تغيير كلمة المرور، و«نسيت كلمة المرور؟» بيبعت رابط على الإيميل.

### تنسيق النصوص
- `[[كلمة]]` ← تلوين ذهبي (زي «You Seek» في الواجهة)
- `{{كلمة}}` ← تلوين أحمر
- `**كلمة**` ← خط عريض
- سطر جديد ← نزول سطر

## الإعداد لأول مرة (مرة واحدة بس — حوالي 5 دقايق)

### 1) اعمل قاعدة البيانات على Supabase (مجاني)
1. ادخل https://supabase.com واعمل حساب، وبعدين **New project**:
   - **Name**: `peak-vision`
   - **Database Password**: أي كلمة سر قوية (احفظها عندك، مش هتحتاجها في اللوحة)
   - **Region**: `Central EU (Frankfurt)` (الأقرب لمصر)
2. **SQL Editor ← New query**: الصق محتوى الملف `supabase/setup.sql` كله، وغيّر `YOUR_EMAIL@example.com` في آخره للإيميل اللي هتدخل بيه اللوحة، واضغط **Run**.
3. **Authentication ← Users ← Add user ← Create new user**: اكتب نفس الإيميل وكلمة المرور، وعلّم على **Auto Confirm User**.
4. **Authentication ← Sign In / Providers**: اقفل **Allow new users to sign up** (عشان محدش يعمل حساب لنفسه).
5. **Authentication ← URL Configuration**: خلّي **Site URL** = `https://peakvision.media/admin/` (ده اللي بيستخدمه رابط «نسيت كلمة المرور»).

### 2) اربط الموقع بقاعدة البيانات
من **Project Settings ← Data API** انسخ **Project URL**، ومن **Project Settings ← API Keys** انسخ مفتاح **anon / publishable**، وحطهم في `assets/config.js`:

```js
window.PV_CONFIG = {
  supabaseUrl: 'https://xxxx.supabase.co',
  supabaseAnonKey: 'المفتاح'
};
```

المفتاح ده **عام ومش سر**: هو بيسمح بقراية محتوى الموقع بس. التعديل محمي بقواعد قاعدة البيانات، ومحدش يقدر يعدّل غير الإيميلات المسموح بيها في `setup.sql` بعد ما يسجّل دخول.

### 3) أول دخول
افتح `peakvision.media/admin`، وادخل بالإيميل وكلمة المرور، واضغط **نشر التغييرات** مرة، عشان المحتوى الحالي يتحفظ في قاعدة البيانات. من بعدها أي تعديل بيظهر على الموقع فورًا.

### إضافة حد تاني يعدّل
1. ضيف حسابه من **Authentication ← Users ← Add user**.
2. ضيف الإيميل بتاعه في قايمة المسموح بيهم: من **SQL Editor** شغّل:

```sql
insert into public.admin_emails (email) values ('his-email@example.com');
```

ولشيل حد: امسح حسابه من **Authentication ← Users**، وامسح الإيميل بتاعه من جدول `admin_emails`.

## التشغيل على جهازك

الموقع لازم يشتغل من سيرفر (مش بفتح الملف بالدبل كليك):

```bash
python3 -m http.server 8000
```

وبعدين افتح `http://localhost:8000` للموقع و `http://localhost:8000/admin/` للوحة التحكم.
